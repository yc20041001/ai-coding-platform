# Frontend Smoke Test Plan

## 前置条件

1. 后端服务启动: `cd backend && mvn spring-boot:run`
2. 前端开发服务器启动: `cd frontend && npm run dev`
3. 测试账号: `admin@example.com` / `Admin@123456`
4. 浏览器打开 `http://localhost:5173`

## 测试场景

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1.1 | 访问 `http://localhost:5173` | 自动跳转到 `/login` |

## 非功能验证

| 项目 | 验证项 | 通过标准 |
|---|---|---|
| N1 | Loading 状态 | 数据加载时显示 v-loading 或 LoadingState |
| N2 | Empty 状态 | 无数据时显示 EmptyState 组件 |
| N3 | Error 状态 | 加载失败时显示 ErrorState，可点击重试 |
| N4 | 类型检查 | `npm run typecheck` 0 错误 |
| N5 | 构建 | `npm run build` 成功 |

## 已知限制

- Repository clone/pull 依赖后端和本地 Git 环境，可能报错
- Member 邀请可能不触发真实邮件通知
- RAG 搜索依赖知识库中有已分块的文档
- Model Usage / Audit Logs 数据依赖历史操作记录
